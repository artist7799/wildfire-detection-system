# 🔥 AI-Based Wildfire Detection System

## 📌 Overview
This project is an AI-powered wildfire detection and alert system developed using Flask, YOLOv8, ESP32, and IoT sensors. The system detects fire and smoke in real time and sends SMS alerts with captured images.

---

## ⚙️ Features
- Real-time wildfire detection
- ESP32 smoke sensor integration
- YOLOv8 fire detection model
- Automatic image capture
- Cloudinary image upload
- SMS alerts using Twilio
- Web dashboard monitoring

---

## 🛠️ Technologies Used
- Python
- Flask
- YOLOv8
- OpenCV
- ESP32
- Cloudinary
- Twilio API
- HTML/CSS/JavaScript

---

## 🔄 System Workflow
1. ESP32 sends smoke values
2. Flask backend receives sensor data
3. Camera captures image when threshold exceeds
4. YOLOv8 detects fire/smoke
5. Image uploaded to Cloudinary
6. SMS alert sent to user

---

## 🚀 Run the Project

```bash
pip install -r requirements.txt
python app.py
```
